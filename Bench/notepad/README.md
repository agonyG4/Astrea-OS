# notepad

Editor de notas rich text em QML/Quickshell inspirado no Notas do macOS.

## Rodar

```sh
cd /home/agony/GitHub/Bench
qs -p notepad
```

## Atalhos

- `Ctrl+N`: novo documento
- `Ctrl+O`: abrir arquivo
- `Ctrl+S`: salvar
- `Ctrl+Shift+S`: salvar como
- `Ctrl+Q`: sair

Arquivos sem extensao escolhidos no "Salvar como" recebem `.html` automaticamente para preservar titulo, estilo, cor e imagens.
