# MacMinimizeDemo

Minimal Quickshell/QML window for Hyprland with macOS-style top buttons.

Only the yellow minimize button is active. It freezes the current window surface,
plays a shrinking minimize animation, then asks the compositor to minimize the
window.

Run it with:

```sh
quickshell -p /home/agony/GitHub/Bench/MacMinimizeDemo/Main.qml
```
